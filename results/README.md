## Метаданные

Файлы environment-UUID.json в корне raw создаются при подготовке запуска.

Манифест внутри каталога серии связан с записями прогонов через SHA-256.

Некоторые ранние серии созданы до полного сбора метаданных и не поддерживаются текущим анализатором.

## Соответствие версий кода

Измерения сохранены без изменений.

В environment.json записан хеш коммита, который существовал во время запуска.

После очистки истории хеши изменились.

Код, конфигурации и измерения в соответствующих коммитах сохранены, из истории удалены MD-файлы и изменены сведения об авторе.
