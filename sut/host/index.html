Сравнение подходов к интеграции WebAssembly

Три микрофронтенда обрабатывают одно изображение. Сравниваются независимое подключение WASM, централизованная доставка и общая среда выполнения.

Изображение

Сценарии

Готовые последовательности действий для проверки WASM. Каждый запуск восстанавливает исходное изображение и создаёт новые среды выполнения.

Фильтрация, уменьшение и анализ выполняются по очереди. Проверяем, сколько экземпляров создают три микрофронтенда.

Фильтрация и уменьшение одновременно запрашивают WASM для исходного изображения. Проверяем, не создаётся ли общий экземпляр дважды. Результаты двух веток появятся ниже.

Пять операций подряд: инверсия, отражение, анализ, яркость и ещё одно отражение. Проверяем повторное использование экземпляров.

«Обращение» означает вызов функции WASM. Конкурентный запуск не означает вычисление в разных потоках. Сброс не очищает HTTP-кэш браузера.
